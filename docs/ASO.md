# App Store Optimization notes

**Name:** FFmpeg Video Compressor

**Short description:** Compress and convert videos locally with FFmpeg.

**Full description (structure):**

1. Opening — Local video compressor. Files never leave the phone.
2. What it does — Compress, resize, change frame rate, switch codec and container.
3. Codecs — H.264, HEVC, AV1 (when the build includes them), AAC, Opus. MP4, MKV, WebM.
4. Presets — Instagram Reels, Instagram Story, High Quality, Small File, Custom.
5. Privacy — No account, no upload, no analytics.
6. Engine — Native builds use official FFmpeg 9.0.1 once the NDK layer is linked.

**Screenshot concepts**

1. Empty state with Select video and “Local only”
2. Metadata card (thumbnail, size, codec, FPS)
3. Preset row (Reels / Story / High Quality / Small File)
4. Processing with real percent and Cancel
5. Before/after sizes
6. Privacy / About with the real FFmpeg version string

**Icon:** Dark rounded tile, film frame, downward chevron (compression). Not the official FFmpeg mark.

**Keywords (natural):** video compressor, video converter, FFmpeg, compress video, reduce video size, MP4 converter, video resize, video bitrate, H.264, HEVC, local video compressor.
